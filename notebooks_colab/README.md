# Novelty Package Scripts (Items 1–7)

Colab scripts implementing the 7-part novelty package added to the AARDF/SATA
paper. Each script expects Google Drive mounted at
`/content/drive/MyDrive/adversarial_iot_paper/` with the same folder
structure used throughout this project (see main repository README for the
base structure: `models/` or `models_v2/`, `results/section6_v2/`,
`results/section7_v2/`, etc.).

## diagnostics/

Diagnostic scripts kept for transparency/audit — they document how two real
bugs were found during this package's development (both already fixed in the
scripts above; neither affects any DEPLOY/REASSESS decision reported in the
paper):

- `diagnostic_cd_check.py` — found that `cd_results_v2.json` /
  `ca_results_v2.json` store the XGBoost model under the key `'XGB'`, not
  `'XGBoost'`, causing `ASR_cross` to silently read as undefined for XGBoost
  in earlier analysis. Fixed via a `CD_MODEL_ALIAS` mapping in all
  downstream scripts.
- `item3_diagnostic_colab.py` — checked which trained-model and raw-data
  files exist on Drive before building the Gaussian-noise-injection
  pipeline (confirms `models_v2/` is the correct folder, and that no raw
  adversarial-example arrays were saved, so Item 3 regenerates FGSM/PGD
  attacks from the original attack code rather than reusing cached
  examples).

## Reproducibility notes

- All scripts use `SEED = 42` for any random sampling, consistent with the
  rest of this repository.
- Item 3's recomputed `asr_before` values will be close to, but not
  bit-for-bit identical to, the values in `defense_results_v2.json`
  (Feature Squeezing), because the two evaluations draw independent random
  3,000-sample subsets from the test set. This is expected and does not
  affect the validity of either evaluation's own before/after comparison.
- Items 1, 2, 4, 6, and 7 are pure post-hoc analyses of already-computed
  benchmark data — no GPU or adversarial-attack computation is required to
  run them. Item 3 requires a GPU-backed Colab runtime (regenerates FGSM/PGD
  attacks).
